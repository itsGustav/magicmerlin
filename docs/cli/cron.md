# `magicmerlin cron`

> CLI command reference

## Usage

```
magicmerlin cron [OPTIONS]
```

## Description

The `cron` command provides cron functionality for MagicMerlin. Use this
command to manage and interact with cron features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin cron

# With JSON output
magicmerlin cron --json

# Verbose mode
magicmerlin cron --verbose
```
