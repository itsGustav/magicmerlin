# `magicmerlin secrets`

> CLI command reference

## Usage

```
magicmerlin secrets [OPTIONS]
```

## Description

The `secrets` command provides secrets functionality for MagicMerlin. Use this
command to manage and interact with secrets features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin secrets

# With JSON output
magicmerlin secrets --json

# Verbose mode
magicmerlin secrets --verbose
```
