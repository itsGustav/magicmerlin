# `magicmerlin directory`

> CLI command reference

## Usage

```
magicmerlin directory [OPTIONS]
```

## Description

The `directory` command provides directory functionality for MagicMerlin. Use this
command to manage and interact with directory features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin directory

# With JSON output
magicmerlin directory --json

# Verbose mode
magicmerlin directory --verbose
```
