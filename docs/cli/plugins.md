# `magicmerlin plugins`

> CLI command reference

## Usage

```
magicmerlin plugins [OPTIONS]
```

## Description

The `plugins` command provides plugins functionality for MagicMerlin. Use this
command to manage and interact with plugins features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin plugins

# With JSON output
magicmerlin plugins --json

# Verbose mode
magicmerlin plugins --verbose
```
