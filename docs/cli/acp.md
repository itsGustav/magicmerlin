# `magicmerlin acp`

> CLI command reference

## Usage

```
magicmerlin acp [OPTIONS]
```

## Description

The `acp` command provides acp functionality for MagicMerlin. Use this
command to manage and interact with acp features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin acp

# With JSON output
magicmerlin acp --json

# Verbose mode
magicmerlin acp --verbose
```
