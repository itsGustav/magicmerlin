# `magicmerlin webhooks`

> CLI command reference

## Usage

```
magicmerlin webhooks [OPTIONS]
```

## Description

The `webhooks` command provides webhooks functionality for MagicMerlin. Use this
command to manage and interact with webhooks features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin webhooks

# With JSON output
magicmerlin webhooks --json

# Verbose mode
magicmerlin webhooks --verbose
```
