# `magicmerlin config`

> CLI command reference

## Usage

```
magicmerlin config [OPTIONS]
```

## Description

The `config` command provides config functionality for MagicMerlin. Use this
command to manage and interact with config features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin config

# With JSON output
magicmerlin config --json

# Verbose mode
magicmerlin config --verbose
```
