# `magicmerlin dashboard`

> CLI command reference

## Usage

```
magicmerlin dashboard [OPTIONS]
```

## Description

The `dashboard` command provides dashboard functionality for MagicMerlin. Use this
command to manage and interact with dashboard features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin dashboard

# With JSON output
magicmerlin dashboard --json

# Verbose mode
magicmerlin dashboard --verbose
```
