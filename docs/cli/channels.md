# `magicmerlin channels`

> CLI command reference

## Usage

```
magicmerlin channels [OPTIONS]
```

## Description

The `channels` command provides channels functionality for MagicMerlin. Use this
command to manage and interact with channels features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin channels

# With JSON output
magicmerlin channels --json

# Verbose mode
magicmerlin channels --verbose
```
