# `magicmerlin approvals`

> CLI command reference

## Usage

```
magicmerlin approvals [OPTIONS]
```

## Description

The `approvals` command provides approvals functionality for MagicMerlin. Use this
command to manage and interact with approvals features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin approvals

# With JSON output
magicmerlin approvals --json

# Verbose mode
magicmerlin approvals --verbose
```
