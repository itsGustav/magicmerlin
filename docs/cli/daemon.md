# `magicmerlin daemon`

> CLI command reference

## Usage

```
magicmerlin daemon [OPTIONS]
```

## Description

The `daemon` command provides daemon functionality for MagicMerlin. Use this
command to manage and interact with daemon features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin daemon

# With JSON output
magicmerlin daemon --json

# Verbose mode
magicmerlin daemon --verbose
```
