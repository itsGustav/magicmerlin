# `magicmerlin doctor`

> CLI command reference

## Usage

```
magicmerlin doctor [OPTIONS]
```

## Description

The `doctor` command provides doctor functionality for MagicMerlin. Use this
command to manage and interact with doctor features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin doctor

# With JSON output
magicmerlin doctor --json

# Verbose mode
magicmerlin doctor --verbose
```
