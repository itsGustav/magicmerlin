# `magicmerlin message`

> CLI command reference

## Usage

```
magicmerlin message [OPTIONS]
```

## Description

The `message` command provides message functionality for MagicMerlin. Use this
command to manage and interact with message features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin message

# With JSON output
magicmerlin message --json

# Verbose mode
magicmerlin message --verbose
```
