# `magicmerlin sessions`

> CLI command reference

## Usage

```
magicmerlin sessions [OPTIONS]
```

## Description

The `sessions` command provides sessions functionality for MagicMerlin. Use this
command to manage and interact with sessions features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin sessions

# With JSON output
magicmerlin sessions --json

# Verbose mode
magicmerlin sessions --verbose
```
