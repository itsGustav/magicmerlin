# `magicmerlin clawbot`

> CLI command reference

## Usage

```
magicmerlin clawbot [OPTIONS]
```

## Description

The `clawbot` command provides clawbot functionality for MagicMerlin. Use this
command to manage and interact with clawbot features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin clawbot

# With JSON output
magicmerlin clawbot --json

# Verbose mode
magicmerlin clawbot --verbose
```
