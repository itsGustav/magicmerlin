# `magicmerlin setup`

> CLI command reference

## Usage

```
magicmerlin setup [OPTIONS]
```

## Description

The `setup` command provides setup functionality for MagicMerlin. Use this
command to manage and interact with setup features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin setup

# With JSON output
magicmerlin setup --json

# Verbose mode
magicmerlin setup --verbose
```
