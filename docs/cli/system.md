# `magicmerlin system`

> CLI command reference

## Usage

```
magicmerlin system [OPTIONS]
```

## Description

The `system` command provides system functionality for MagicMerlin. Use this
command to manage and interact with system features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin system

# With JSON output
magicmerlin system --json

# Verbose mode
magicmerlin system --verbose
```
