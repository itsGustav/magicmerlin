# `magicmerlin status`

> CLI command reference

## Usage

```
magicmerlin status [OPTIONS]
```

## Description

The `status` command provides status functionality for MagicMerlin. Use this
command to manage and interact with status features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin status

# With JSON output
magicmerlin status --json

# Verbose mode
magicmerlin status --verbose
```
