# `magicmerlin agent`

> CLI command reference

## Usage

```
magicmerlin agent [OPTIONS]
```

## Description

The `agent` command provides agent functionality for MagicMerlin. Use this
command to manage and interact with agent features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin agent

# With JSON output
magicmerlin agent --json

# Verbose mode
magicmerlin agent --verbose
```
