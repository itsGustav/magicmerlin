# `magicmerlin memory`

> CLI command reference

## Usage

```
magicmerlin memory [OPTIONS]
```

## Description

The `memory` command provides memory functionality for MagicMerlin. Use this
command to manage and interact with memory features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin memory

# With JSON output
magicmerlin memory --json

# Verbose mode
magicmerlin memory --verbose
```
