# `magicmerlin docs`

> CLI command reference

## Usage

```
magicmerlin docs [OPTIONS]
```

## Description

The `docs` command provides docs functionality for MagicMerlin. Use this
command to manage and interact with docs features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin docs

# With JSON output
magicmerlin docs --json

# Verbose mode
magicmerlin docs --verbose
```
