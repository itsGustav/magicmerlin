# `magicmerlin dns`

> CLI command reference

## Usage

```
magicmerlin dns [OPTIONS]
```

## Description

The `dns` command provides dns functionality for MagicMerlin. Use this
command to manage and interact with dns features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin dns

# With JSON output
magicmerlin dns --json

# Verbose mode
magicmerlin dns --verbose
```
