# `magicmerlin gateway`

> CLI command reference

## Usage

```
magicmerlin gateway [OPTIONS]
```

## Description

The `gateway` command provides gateway functionality for MagicMerlin. Use this
command to manage and interact with gateway features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin gateway

# With JSON output
magicmerlin gateway --json

# Verbose mode
magicmerlin gateway --verbose
```
