# `magicmerlin tui`

> CLI command reference

## Usage

```
magicmerlin tui [OPTIONS]
```

## Description

The `tui` command provides tui functionality for MagicMerlin. Use this
command to manage and interact with tui features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin tui

# With JSON output
magicmerlin tui --json

# Verbose mode
magicmerlin tui --verbose
```
