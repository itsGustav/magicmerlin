# `magicmerlin voicecall`

> CLI command reference

## Usage

```
magicmerlin voicecall [OPTIONS]
```

## Description

The `voicecall` command provides voicecall functionality for MagicMerlin. Use this
command to manage and interact with voicecall features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin voicecall

# With JSON output
magicmerlin voicecall --json

# Verbose mode
magicmerlin voicecall --verbose
```
