# `magicmerlin completion`

> CLI command reference

## Usage

```
magicmerlin completion [OPTIONS]
```

## Description

The `completion` command provides completion functionality for MagicMerlin. Use this
command to manage and interact with completion features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin completion

# With JSON output
magicmerlin completion --json

# Verbose mode
magicmerlin completion --verbose
```
