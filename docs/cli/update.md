# `magicmerlin update`

> CLI command reference

## Usage

```
magicmerlin update [OPTIONS]
```

## Description

The `update` command provides update functionality for MagicMerlin. Use this
command to manage and interact with update features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin update

# With JSON output
magicmerlin update --json

# Verbose mode
magicmerlin update --verbose
```
