# `magicmerlin browser`

> CLI command reference

## Usage

```
magicmerlin browser [OPTIONS]
```

## Description

The `browser` command provides browser functionality for MagicMerlin. Use this
command to manage and interact with browser features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin browser

# With JSON output
magicmerlin browser --json

# Verbose mode
magicmerlin browser --verbose
```
