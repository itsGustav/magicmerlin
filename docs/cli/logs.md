# `magicmerlin logs`

> CLI command reference

## Usage

```
magicmerlin logs [OPTIONS]
```

## Description

The `logs` command provides logs functionality for MagicMerlin. Use this
command to manage and interact with logs features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin logs

# With JSON output
magicmerlin logs --json

# Verbose mode
magicmerlin logs --verbose
```
