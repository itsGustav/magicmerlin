# `magicmerlin onboard`

> CLI command reference

## Usage

```
magicmerlin onboard [OPTIONS]
```

## Description

The `onboard` command provides onboard functionality for MagicMerlin. Use this
command to manage and interact with onboard features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin onboard

# With JSON output
magicmerlin onboard --json

# Verbose mode
magicmerlin onboard --verbose
```
