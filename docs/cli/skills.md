# `magicmerlin skills`

> CLI command reference

## Usage

```
magicmerlin skills [OPTIONS]
```

## Description

The `skills` command provides skills functionality for MagicMerlin. Use this
command to manage and interact with skills features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin skills

# With JSON output
magicmerlin skills --json

# Verbose mode
magicmerlin skills --verbose
```
