# `magicmerlin nodes`

> CLI command reference

## Usage

```
magicmerlin nodes [OPTIONS]
```

## Description

The `nodes` command provides nodes functionality for MagicMerlin. Use this
command to manage and interact with nodes features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin nodes

# With JSON output
magicmerlin nodes --json

# Verbose mode
magicmerlin nodes --verbose
```
