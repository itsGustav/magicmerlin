# `magicmerlin pairing`

> CLI command reference

## Usage

```
magicmerlin pairing [OPTIONS]
```

## Description

The `pairing` command provides pairing functionality for MagicMerlin. Use this
command to manage and interact with pairing features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin pairing

# With JSON output
magicmerlin pairing --json

# Verbose mode
magicmerlin pairing --verbose
```
