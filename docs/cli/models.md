# `magicmerlin models`

> CLI command reference

## Usage

```
magicmerlin models [OPTIONS]
```

## Description

The `models` command provides models functionality for MagicMerlin. Use this
command to manage and interact with models features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin models

# With JSON output
magicmerlin models --json

# Verbose mode
magicmerlin models --verbose
```
