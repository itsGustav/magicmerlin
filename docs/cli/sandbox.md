# `magicmerlin sandbox`

> CLI command reference

## Usage

```
magicmerlin sandbox [OPTIONS]
```

## Description

The `sandbox` command provides Sandbox CLI functionality for MagicMerlin. Use this
command to manage and interact with sandbox cli features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin sandbox

# With JSON output
magicmerlin sandbox --json

# Verbose mode
magicmerlin sandbox --verbose
```
