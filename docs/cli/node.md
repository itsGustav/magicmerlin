# `magicmerlin node`

> CLI command reference

## Usage

```
magicmerlin node [OPTIONS]
```

## Description

The `node` command provides node functionality for MagicMerlin. Use this
command to manage and interact with node features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin node

# With JSON output
magicmerlin node --json

# Verbose mode
magicmerlin node --verbose
```
