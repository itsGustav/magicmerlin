# `magicmerlin security`

> CLI command reference

## Usage

```
magicmerlin security [OPTIONS]
```

## Description

The `security` command provides security functionality for MagicMerlin. Use this
command to manage and interact with security features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin security

# With JSON output
magicmerlin security --json

# Verbose mode
magicmerlin security --verbose
```
