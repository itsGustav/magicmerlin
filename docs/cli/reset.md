# `magicmerlin reset`

> CLI command reference

## Usage

```
magicmerlin reset [OPTIONS]
```

## Description

The `reset` command provides reset functionality for MagicMerlin. Use this
command to manage and interact with reset features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin reset

# With JSON output
magicmerlin reset --json

# Verbose mode
magicmerlin reset --verbose
```
