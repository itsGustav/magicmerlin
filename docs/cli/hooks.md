# `magicmerlin hooks`

> CLI command reference

## Usage

```
magicmerlin hooks [OPTIONS]
```

## Description

The `hooks` command provides hooks functionality for MagicMerlin. Use this
command to manage and interact with hooks features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin hooks

# With JSON output
magicmerlin hooks --json

# Verbose mode
magicmerlin hooks --verbose
```
