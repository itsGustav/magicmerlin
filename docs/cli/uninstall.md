# `magicmerlin uninstall`

> CLI command reference

## Usage

```
magicmerlin uninstall [OPTIONS]
```

## Description

The `uninstall` command provides uninstall functionality for MagicMerlin. Use this
command to manage and interact with uninstall features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin uninstall

# With JSON output
magicmerlin uninstall --json

# Verbose mode
magicmerlin uninstall --verbose
```
