# `magicmerlin devices`

> CLI command reference

## Usage

```
magicmerlin devices [OPTIONS]
```

## Description

The `devices` command provides devices functionality for MagicMerlin. Use this
command to manage and interact with devices features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin devices

# With JSON output
magicmerlin devices --json

# Verbose mode
magicmerlin devices --verbose
```
