# `magicmerlin agents`

> CLI command reference

## Usage

```
magicmerlin agents [OPTIONS]
```

## Description

The `agents` command provides agents functionality for MagicMerlin. Use this
command to manage and interact with agents features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin agents

# With JSON output
magicmerlin agents --json

# Verbose mode
magicmerlin agents --verbose
```
