# `magicmerlin health`

> CLI command reference

## Usage

```
magicmerlin health [OPTIONS]
```

## Description

The `health` command provides health functionality for MagicMerlin. Use this
command to manage and interact with health features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin health

# With JSON output
magicmerlin health --json

# Verbose mode
magicmerlin health --verbose
```
