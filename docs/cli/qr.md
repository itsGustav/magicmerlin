# `magicmerlin qr`

> CLI command reference

## Usage

```
magicmerlin qr [OPTIONS]
```

## Description

The `qr` command provides qr functionality for MagicMerlin. Use this
command to manage and interact with qr features directly from the
terminal.

## Options

| Flag | Description |
|------|-------------|
| `--help` | Show help information |
| `--json` | Output as JSON |
| `--verbose` | Enable verbose output |
| `--quiet` | Suppress non-essential output |

## Examples

```bash
# Basic usage
magicmerlin qr

# With JSON output
magicmerlin qr --json

# Verbose mode
magicmerlin qr --verbose
```
